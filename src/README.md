# Student Grade System

A simple Java project that calculates a student's average grade and determines whether the student passed or failed.

## Features
- Displays student information
- Calculates the average of three grades
- Checks whether the student passed or failed
- Displays the final average

## Technologies Used
- Java
- Object-Oriented Programming (OOP)

## Passing Criteria
A student passes if their average grade is 75 or higher.

## How to Run
1. Open the project in IntelliJ IDEA.
2. Run `Main.java`.
3. View the student's information, average grade, and result in the console.

## Purpose
This project was created to practice Java classes, objects, constructors, methods, and conditional statements.
